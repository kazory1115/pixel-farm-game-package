# 回歸基準

`fixtures/legacy-baseline.json` 是從重構前的單檔遊戲執行 `scenarios.mjs` 擷取的結果，包含原始 HTML 的 SHA-256、初始亂數種子與時間、DOM／CSS／圖片雜湊，以及各流程的狀態和繪圖紀錄雜湊。

`runtime.mjs` 使用 Node.js VM 提供可控制的 DOM、Canvas、時間與輸入邊界。Canvas 紀錄包含樣式、圖片內容雜湊、圖片原始尺寸、座標、文字、縮放與繪圖順序；它不會實際繪製像素，也不會播放 WebAudio。一般回歸測試等待模擬圖片與字型準備完成後再操作，實際瀏覽器的網速、解碼成本與 GPU 效能不在測試範圍內。

`npm test` 同時測試根目錄的 `index.html`，以及在暫存目錄即時建立的單檔 `index.html`。測試確認首頁直接啟動遊戲、沒有轉址或 iframe。匯出測試不依賴既有 `dist/`，結束後會刪除測試產物。

原版快照是架構重構的行為合約。若後續刻意改變遊戲行為，請先補上該需求的明確斷言，再審查對應快照差異，不要直接以新版輸出覆蓋整份基準。

`interaction-fixes.mjs` 另外驗證商店室內 START 選單、長對話分頁／旋轉／取消，以及手機方向鍵、長按、滑動與點選。這些是後續授權修正的原版問題：狀態比對忽略新增的 `dialogue.pageStart`；七種尺寸下的商店 START 畫面改由明確的文字與操作斷言驗證，其餘舊版快照仍照常核對，原始基準沒有重錄。

場景直接點擊也已取消。測試對滑鼠與觸控分別驗證：土地、作物、雞蛋、建築及對話都不會因點擊場景而改變狀態；方向鍵移動後仍可用 A 操作面前格子。原本觸控流程中「點擊遠處土地」的單一快照改為斷言狀態完全不變，其餘快照繼續與原版比對。選單與交易面板的點選保留。

`startup.mjs` 另外模擬圖片下載／解碼延遲、載入與解碼失敗、30 秒圖片逾時、首屏中文字型預載、字型失敗／2.5 秒逾時／晚到回應、無解碼 API、無字型 API，以及重複 resize。測試確認準備期間不啟動遊戲迴圈或綁定遊戲輸入，首幀畫完才隱藏載入層，字型逾時後不再改變畫面字型。

首頁多出的載入 section 與 CSS 以獨立區塊管理；原版的遊戲版面與樣式雜湊比對會排除這些新增區塊，圖片位元組與既有遊戲回歸基準保持原樣。
