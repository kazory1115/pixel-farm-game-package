# 回歸基準

`fixtures/legacy-baseline.json` 是從重構前的單檔遊戲執行 `scenarios.mjs` 擷取的結果，包含原始 HTML 的 SHA-256、初始亂數種子與時間、DOM／CSS／圖片雜湊，以及各流程的狀態和繪圖紀錄雜湊。

`runtime.mjs` 使用 Node.js VM 提供可控制的 DOM、Canvas、時間與輸入邊界。Canvas 紀錄包含樣式、圖片內容雜湊、圖片原始尺寸、座標、文字、縮放與繪圖順序；它不會實際繪製像素，也不會播放 WebAudio。一般回歸測試等待模擬圖片與字型準備完成後再操作，實際瀏覽器的網速、解碼成本與 GPU 效能不在測試範圍內。

`npm test` 同時測試根目錄的 `index.html`，以及在暫存目錄即時建立的單檔 `index.html`。測試確認首頁直接啟動遊戲、沒有轉址或 iframe。匯出測試不依賴既有 `dist/`，結束後會刪除測試產物。

原版快照是架構重構的行為合約。若後續刻意改變遊戲行為，請先補上該需求的明確斷言，再審查對應快照差異，不要直接以新版輸出覆蓋整份基準。

`interaction-fixes.mjs` 另外驗證商店室內 START 選單、長對話分頁／旋轉／取消，以及手機方向鍵、長按、滑動與點選。這些是後續授權修正的原版問題：狀態比對忽略新增的 `dialogue.pageStart`；七種尺寸下的商店 START 畫面改由明確的文字與操作斷言驗證，其餘舊版快照仍照常核對，原始基準沒有重錄。

場景直接點擊也已取消。測試對滑鼠與觸控分別驗證：土地、作物、雞蛋、建築及對話都不會因點擊場景而改變狀態；方向鍵移動後仍可用 A 操作面前格子。原本觸控流程中「點擊遠處土地」的單一快照改為斷言狀態完全不變，其餘快照繼續與原版比對。選單與交易面板的點選保留。

`startup.mjs` 另外模擬圖片下載／解碼延遲、載入與解碼失敗、30 秒圖片逾時、首屏中文字型預載、字型失敗／2.5 秒逾時／晚到回應、無解碼 API、無字型 API，以及重複 resize。測試確認準備期間不啟動遊戲迴圈或綁定遊戲輸入，首幀畫完才隱藏載入層，字型逾時後不再改變畫面字型。

首頁多出的載入 section 與 CSS 以獨立區塊管理；原版的遊戲版面與樣式雜湊比對會排除這些新增區塊，圖片位元組與既有遊戲回歸基準保持原樣。

`field-test-fixes.mjs` 對應 30 天實測回報，驗證肥料選取與背包、世界文字與面板的合成次序、翻土與澆水標記、動物雙向碰撞與禁入田地、雞舍入口雙向通行，以及南排 7 格可種植收成；另補上 30 天市集價格與灑水器購買／鄰格澆水。動物路徑已刻意改變，舊快照只略過其精確座標與下蛋位置，仍核對物種、數量、玩家、農場、暫停與其他狀態；另以 2,400 次動物更新斷言活動範圍。

`fixtures/field-test-render-baseline.json` 是本次修正後經實際畫面檢查的繪圖快照，涵蓋兩階段文字合成、上方對話框、完整道具清單、存檔選項、雞舍入口與攤位邊界。`legacy-baseline.json` 保持原樣；原有 54 張圖片仍逐一核對原版位元組。舊版移動路線會先設定朝向再走格，原地轉向另外驗證。

`save-and-turn.mjs` 驗證鍵盤／觸控原地轉向、長按走路、不跳兩格、幀間快速點按、自動／手動存檔、關頁／隱藏時存檔、重載完整進度、商店內續玩、換日中斷、移動中存檔，以及資料損毀與瀏覽器禁止儲存時的回復。

動物避讓另驗證四種陸上動物對單次短按讓路、連續穿越多隻動物、讓路期間不與玩家重疊、不進田地或穿圍欄，以及轉向／開選單取消等待中的一步；入口小木牌沿用世界文字的面板遮擋規則。
避讓與巡遊會改變亂數取用順序，因此動物情境的自然下蛋不再要求與舊版完全相同的隨機數量，但仍核對最多四顆、不重複、出現在圍欄內，以及撿蛋後的農場狀態。

可用已安裝的 Chrome 執行 `node tests/browser-smoke.mjs`；其他 Chromium 路徑可透過 `BROWSER_PATH` 指定。這項檢查使用暫存瀏覽器設定檔與本機伺服器，驗證五種視窗、四種按鈕大小的對話框／控制項邊界、面板實際像素、重新整理接續存檔與原地轉向，並印出截圖暫存目錄。


`phase-one.mjs` 驗證水圖偶發下載／解碼失敗後的自動重試、實際字寬分頁、四向身形碰撞、動物彼此避讓、舊重疊存檔修復、套組交付／領獎與防重複領取。

`exploration.mjs` 驗證擴大地圖與雙向出口、M 地圖、晝夜推進及暫停、交易開關門邊界、已開交易面板不能繞過休市、長椅等開市、NPC 任務、集章與每日拾趣、區域與日誌續存、舊存檔預設值，以及一般農作不再彈出阻擋對話。

`fixtures/phase-one-render-baseline.json` 是本階段刻意變更的繪圖基準；保留原本兩份歷史基準。原版情境繼續核對農場數值、背包、農作、生長、販售與操作狀態；動物的精確座標、原版邊界外新增的可走區、已改成短訊息的對話狀態及新增目標列，改由明確的功能測試驗證。圖片檢查仍逐一核對原有 54 張位元組，匯出另包含新增灑水器。

真實瀏覽器測試額外檢查所有控制項仍在遊戲畫布內、保留側邊安全間距且不遮住玩家，並留下澆水與灑水器、市集日景／夜景及手機地圖截圖。WSL 可使用 Windows Node 執行同一支測試，避免 Windows Chrome 與 WSL 本機網路不同的問題。
