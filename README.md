# 像素農場小遊戲

星露谷式小農場遊戲，使用原生 JavaScript 與 Canvas。畫面、素材、遊戲規則和操作沿用原版，開發程式已拆成獨立模組。直接雙擊根目錄的 `index.html` 就能玩，不需要安裝套件、架伺服器或連網。離線時字體會退回系統字體。

開發版需要保留 `src/`、`styles/` 和 `assets/game/` 的相對位置。如果只想分享一個 HTML 檔，使用下方的單檔匯出指令。

開發、GitHub Pages 與單檔匯出統一使用 `index.html` 作為唯一入口。GitHub Pages 使用 `master` 的 `/(root)` 發布時，網站首頁直接載入遊戲，網址維持在網站根路徑。

## 怎麼玩

- 移動：WASD／方向鍵，手機使用畫面上的方向按鈕。輕按不同方向會原地轉身，持續按住約 0.12 秒才往新方向移動；面向同方向時輕按前進一格。
- A 互動：Z／空白鍵／E，或點畫面上的 A。依目前工具與面前格子進行翻土、播種、澆水、收成、開門與對話。
- 場景中的土地、作物、雞蛋、建築與物品不接受直接點擊；先移動、面向目標，再按 A。對話也以 A 繼續、B 取消。選單與商店／市集面板仍可點選，選單清單可滑動。
- B 取消：X／Esc，或點畫面上的 B。
- 換工具：Shift／SELECT；數字鍵 1–9 可直接選工具。
- 選單：Enter／START，可查看道具、背包、目標與說明。「其他」分頁可調整按鈕大小（80%、100%、120%、140%），按 A 或點選該項切換。
- 選單內可用畫面方向鍵切換項目與分頁，長按可連續移動；手機也能上下滑動清單。
- 長對話分頁顯示：按 A 顯示本頁全文，再按 A 看下一頁；最後一頁按 A 關閉，B 可直接取消。
- 睡覺推進天數，雨天自動澆水；雞會下蛋，可以撿取。

## 商店與市集

- 北邊種子商店：走進室內，面對櫃台買五種種子、肥料（作物提早長大一天）與灑水器（澆水連鄰格一起澆，一次性升級）。
- 南邊市集：面對攤位逐項賣貨或全部賣出，價格每天浮動（基礎價格的 0.75–1.35 倍，再取整數）。行情招牌可以查看今日價格。
- 背包只顯示物品，賣貨需要前往市集。

## 畫面與進度

- 無邊框滿版，視野隨視窗長寬比調整，Canvas 使用最近鄰放大保留像素風格。
- 文字在顯示畫布上另外繪製，保持清晰。
- 進度為單次遊玩制，不保存，重新開啟就是新的一局。按鈕大小是裝置偏好，會保存在瀏覽器中。
- 保留原有 54 張像素素材與星露谷式農場配置。未翻土有小草，翻土後顯示原有犁溝土地；缺水顯示水滴，澆水後換成藍色勾記。雞舍西側石板路與黃色門柱標示出入口。
- 雞舍入口以門柱上的小木牌標示。走向貓、狗、雞或牛時，牠們會挪到安全位置讓路；短按也會在讓路後接著走一格。動物會避開田地，並盡量不停在道路或門口。
- 商店室內也可正常開啟 START 選單；行情等長對話會換頁，手機說明清單可完整捲動閱讀。
- 初次進場會顯示載入進度，54 張圖片下載並解碼、首屏字型準備完成後才顯示遊戲。圖片載入失敗或超過 30 秒會顯示重新載入按鈕。
- 點陣字型採非阻塞載入，會預載首屏實際使用的中文字。若 2.5 秒內未完成，本局固定使用系統字型，避免進場後又切換字型。

## 程式架構

只有 `window.PixelFarm` 一個應用程式命名空間。各模組以工廠函式接收明確的依賴；所有可變遊戲狀態集中在每局獨立的 store。使用一般 script，而非 ES modules，讓 `file://` 直接開啟也能運作。

| 位置 | 責任 |
| --- | --- |
| `index.html` | 遊戲本體的頁面結構與 script 載入順序，也是 GitHub Pages 首頁 |
| `styles/game.css` | 原版滿版版面、觸控按鈕與夜晚遮罩樣式 |
| `src/config.js` | 地圖位置、作物、價格、工具與移動設定 |
| `src/state.js` | 每局的農場、玩家、場景、面板、輸入與動物狀態 |
| `src/assets.js`、`assets/game/` | 遊戲實際使用的 54 張圖片及載入清單 |
| `src/world.js` | 地形、障礙物與碰撞判斷 |
| `src/farming.js`、`src/day.js` | 農作互動、睡覺、天氣與作物生長 |
| `src/player.js`、`src/animals.js` | 玩家移動、動物活動與下蛋 |
| `src/commerce.js` | 商店進出、購買、市集價格與販售 |
| `src/tools.js`、`src/goals.js` | 工具選擇與目標判定 |
| `src/dialogue.js`、`src/menu.js`、`src/audio.js` | 對話、選單資料／操作與音效 |
| `src/render/surface.js` | 畫布、文字佇列、繪圖基本操作與視窗縮放 |
| `src/render/world.js` | 農場建築、作物與商店室內的繪圖元件 |
| `src/render/panels.js` | HUD、對話框、選單、購買與販售面板 |
| `src/render/renderer.js` | 場景、動物的繪圖順序與畫面合成 |
| `src/input.js` | 鍵盤、觸控按鈕，以及選單與交易面板的點選／滑動 |
| `src/startup.js` | 載入進度、首屏字型準備、逾時回退與載入失敗提示 |
| `src/main.js` | 組合服務、控制暫停與動畫主迴圈 |
| `src/bootstrap.js` | 建立並啟動遊戲 |
| `scripts/` | 單檔匯出與語法檢查，只有開發工具使用 Node.js |
| `tests/` | 原版行為快照與開發版／匯出版回歸測試 |
| `assets/`、`assets-shop/` | 保留最初的素材原圖，不是遊戲執行時的依賴 |

新增模組時，把 script 加入 HTML，然後在 `src/main.js` 組合服務；匯出工具會自動沿用 HTML 的載入順序。調整遊戲規則時改對應服務，調整畫面時改 `src/render/` 或 CSS。

## 開發檢查與單檔匯出

需要 Node.js 20 以上，不需要 `npm install`。

```sh
npm run check
npm test
npm run build
```

匯出結果為 `dist/index.html`。CSS、JavaScript 與圖片都會內嵌，可以單獨複製分享、雙擊開啟。Google Fonts 仍為選用的外部字體，離線有系統字體可用。

回歸測試以重構前的原版建立固定快照，涵蓋農作、商店、市集、換日、目標、移動、碰撞、鍵盤、觸控與七種視窗尺寸。測試也核對主要 DOM、54 張圖片的位元組、Canvas 繪圖指令與按鈕大小設定。這是模擬瀏覽器環境的比對，不取代實際瀏覽器的視覺與裝置測試。
